# AEC in NFDI4Ing

Astro website for the AEC activities within NFDI4Ing, prepared for static hosting on GitHub Pages and the custom domain [aec.nfdi4ing.de](https://aec.nfdi4ing.de).

## Repository Structure

- `src/pages/`: static routes, including the homepage and 404 page
- `src/layouts/`: shared HTML shell and metadata handling
- `src/components/`: shared header and footer components
- `src/config/`: site metadata and navigation configuration
- `src/styles/`: global design tokens, layout, and component styles
- `public/assets/`: static logos, icons, images, and future downloads
- `.github/workflows/deploy.yml`: GitHub Pages deployment workflow
